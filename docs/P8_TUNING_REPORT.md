试验输入哈希包含基线快照和业务/模拟代码；data的运行前后哈希另作“不修改现场”校验，后续正式落地时data自然会变化。有效候选内容的哈希独立保留。原P8首批报告和JSON按历史版本保留，不能拿它们的旧代码哈希声称匹配当前工作树。
