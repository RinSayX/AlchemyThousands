# P4 炼丹房与本次会话

运行版本：Godot `4.5.stable.official.876b29033`，项目 `0.1.4-p4`。导入 project.godot 按 F5，或运行 `godot --path .`。

## 玩家操作

1. 主菜单选择“启程入宗”，阅读引导后进入丹房。得到原设计的 200 灵石、灵草×5、青花×3、凡铁丹炉、凡火与聚灵丹丹方。
2. 左栏浏览、搜索、按品阶筛选丹方，查看材料持有/需要数量。“购药”购买 1～10 炉完整药材，不含符箓。可购买丹方显示研习入口，境界不足时禁用。
3. 右栏选择已拥有装备、最多一件符箓与正常/稳妥/冲品策略。未拥有装备禁选，符箓可单独购买；概率、条件品质分布、单炉极品率和返还来自同一引擎预览。
4. “开炉”立即锁定本炉操作，五秒后揭晓；可点击跳过或按 Esc。快速揭晓与沉静模式不等待。动画为装饰，与 RNG 无关，也不通过奖励或售价提前透露结果。
5. 结果显示品质/数量，或失败丹渣、耗材/返还、经验/心得。可保留产物，也可出售背包内全部丹药与丹渣；不会出售药材、符箓或装备。售出后明确确认收入。
6. 中栏保留最近二十炉，悬停查看消耗与奖励；记录不是再次领奖入口。

Tab / Shift+Tab 导航，Enter / Space 确认。炼制时 Esc 揭晓，结果弹层 Esc 关闭，空闲时 Esc 返回山门。结果弹层阻止背景焦点，售出后将焦点移至继续按钮。

右侧详情可滚动；设计视口 1280×720，最小窗口 960×540。品质有中文名称和数值，不仅靠颜色区分。

## 会话和数据边界

返回山门保留本次会话，“继续本次修行”复用同一状态和丹房，不重复发起始资源。已有会话时重新入宗需确认重置；仅打开或取消引导不会重置。

**关闭程序后进度不保留。** 引导、继续按钮提示和丹房页脚均说明此限制；P4 未实现 SaveManager。

- GameShell 由主场景持有，负责菜单/丹房切换；无新增 Autoload。
- GameSession 持有状态，通过 P2/P3 服务修改资源。初始化结果、状态和历史均与内部集合隔离。UI 不直接改灵石、库存、境界或概率。
- 开炉使用唯一操作 ID，立即结算并缓存待揭晓回执；待揭晓期间禁止再次开炉、交易和重开。揭晓只记录回执，不重复结算。
- Room 有 idle / brewing / result 状态。跳过与计时器同时触发只揭晓一次，购药/售丹有同帧锁；后端仍完整核验交易。
- 动画期间显示开炉前状态和出售报价快照；揭晓时统一刷新，避免顶部奖励、返还或售价提前泄露结果。
- 现有数值、RNG 和交易规则不变；新会话用本机单调计时值设种子，装饰动画不参与玩法随机。

尚无晋升、委托、探索、免费采药、完整商店/背包页、正式图鉴、持久存档或轮回。高阶内容沿用服务锁定，零资源免费恢复由 P5 提供。
