## 0.1.2-p2 · 2026-11-18

- 实现无 UI 依赖的 EconomyService、InventoryService、ShopService 与统一事务结果。

- 新增经济专项测试和临时状态的交易演示，补充 ECONOMY_API.md、P2_REPORT.md。
