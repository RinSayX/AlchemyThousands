## 真实获取、保存与轮回

CatalogRoute 从种子20261119的新修行开始，通过现有晋升脚本的阶段回调：正常采药/休整、基础stable开炉、委托/售丹筹资、定式研制和认证、选择stable天赋，按境界支付所有装备试炼成本；再逐个购买新丹方、向商店及固定秘境取得材料，实际开炉直到新丹成品入库，然后售丹。未注入金钱、境界、材料或结果。入门回灵丹在一品里程碑购买，其余在最低品阶购买炼制。

结果：13张新丹方全部成功成丹，共21次新配方尝试；全程747次概率开炉（含726次基础筹资开炉）、1845次行动，期末1216灵石，取得6炉/5火并完成大宗师认证。相比旧装备演示路线421炉/1061行动，新增支线购买与筹资显著增加操作量。此路线用于可达性证明，未优化支线售丹融资，也不证明真人4～8小时或投资回收时间合理。
