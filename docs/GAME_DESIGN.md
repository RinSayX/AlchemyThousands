# 游戏设计基线

> 摘自根目录完整设计文档 v1.0（2026-11-18）。原章节编号保留。设计规格不代表已实现功能。
> 工程基准：本机 Godot **4.5.stable.official.876b29033**，以 `.godot-version` 为准。

# 1. 项目定位与目标

## 1.1 一句话定义

**开局一座破丹炉，通过公开的概率、资源经营和装备构筑，成为炼丹大宗师；通关后带着有限传承轮回，再走出不同的丹道。**

## 1.2 游戏类型

- **核心类型**：单机炼丹模拟＋轻量经营＋收集＋构筑策略。
- **重玩机制**：轻度 Roguelite，多周目独立开局，保留部分元进度。
- **核心操作**：选择丹方／材料／装备／策略 → 查看概率和成本 → 开炉 → 获取结果 → 出售、交付或收藏。
- **美术表现**：优先 2D 国风 UI；如已有像素风资源，也可采用 2D 像素。避免制作自由移动地图。
- **付费原则**：可以设计为买断制或免费单机，**不做真实金钱赌博、抽奖付费、强制广告**。

## 1.3 时长与体验目标

| 指标 | 设计目标 | 备注 |
|---|---:|---|
| 第一周目主线 | 4～8 小时 | 以约 6 小时为中心值 |
| 第二周目及之后 | 2～3 小时 | 跳过教程、保留快捷功能、加快低阶操作 |
| 单次炼丹结果反馈 | 约 5～15 秒 | 玩家可跳过重复动画 |
| 单次会话 | 10～25 分钟 | 可保存退出 |
| 首个可玩原型 | 20～40 分钟 | 不需要完整通关内容 |
| 初始核心流派 | 3 种 | 稳丹、极品、回收 |
| 通关后的目标 | 新传承、新天地变数、新结局、挑战纪录 | 不强制重复同一剧情 |

### 成功标准

1. 玩家可以在前 10 分钟理解炼丹的收益、概率和失败成本。
2. 玩家在前 30 分钟获得首次明确的装备或丹方升级。
3. 每隔约 20～30 分钟至少出现一项重要新能力、目标或决策。
4. 即使连续失败，也不会永久失去继续炼丹的能力。
5. “稳妥盈利”和“冒险冲极品”都存在合理使用场景。
6. 第二周目通过规则和构筑改变玩法，而不只是重复刷材料。

## 1.4 设计支柱

**P1：炼丹结果值得期待。** 丹炉震动、火焰变化、揭示丹品是关键反馈，但不伪造“差一点中极品”的近失效果。

**P2：概率公开而可算。** 成功率、成功后品质分布、特殊效果触发条件在开炉前可查看；预览和实际判定使用同一规则引擎。

**P3：失败也有积累。** 失败可获得丹渣、经验或研究心得；重要主线关卡有可预计的保底路径。

**P4：构筑有取舍。** 成功率、品质、材料回收、额外出丹不能全由单一装备无代价地最大化。

**P5：可控的短篇体验。** 不引入完整灵田系统，不强制实时等待，不制作庞大地图及即时战斗。

**P6：多周目创造新选择。** 轮回重置资源，但不清除图鉴、便利操作和已解锁传承。

## 1.5 明确不做（首个正式版本）

- 完整种地、浇水、施肥、季节和天气经营。
- 地图自由行走、复杂战斗与角色装备系统。
- 实时体力、离线挂机生产、每日登录奖励。
- 线上排行、多端同步与账号系统。
- 付费概率物品、隐藏动态概率、强制限时活动。
- 开放式无限词条组合器（先用有限的、可控的效果集合）。

# 2. 核心体验与游戏循环

## 2.1 单炉循环

```text
选丹方 → 检查材料与解锁条件 → 配丹炉/异火/消耗品
    → 选择稳妥或冲品 → 展示成功率/品质率/本炉成本
    → 开炉（一次性扣除材料与道具）
    → 判定成功 → 成功后判定品质/变异/多丹
    → 生成产物、经验、研究心得、统计
    → 卖丹 / 交委托 / 留图鉴 / 推研
```

## 2.2 经济循环

```text
灵石 → 购买普通材料 → 炼丹 → 出售或完成委托
    → 获得灵石与资源 → 改善丹炉、异火、丹方
    → 挑战更高品阶 → 获得更高价值的产物
```

## 2.3 风险选择

- **稳丹**：高成功率，适合清委托、积累启动资金。
- **冲品**：较低成功率，但成功后更高概率获得上品与极品；适合图鉴、晋级挑战和高回报订单。
- **回收**：降低失败损失，适合昂贵材料和高难丹方。

玩家每次不必手动完成复杂反应小游戏；通过装备、材料替换和控火策略形成主要决策。

## 2.4 游戏行动单位

为避免“每周目到底持续多久”难以平衡，建议内部统计 **行动数**：一次开炉、一次探索、一次委托交付等可记为行动。行动主要服务于成就、世界事件触发和速度挑战，而不是限制玩家进入游戏。

- 普通商店浏览、装备切换、查看图鉴：不消耗行动。
- 炼丹：每炉消耗 1 次炼丹行动。
- 探索：每进入一次事件消耗 1 次探索行动（可有资源成本）。
- 交付委托：完成后结算，不另收费。
- 批量炼丹：内部按每炉顺序逐次结算，以保证概率、进度与资源正确。

# 3. 世界观、主线与通关节奏

## 3.1 基础设定

天地灵气衰涨，丹道传承散落于宗门、古遗迹与异火禁地。玩家原为边陲宗门丹童，得到一座旧丹炉与半部炼丹手记。通过炼丹考试、宗门委托和古方研究逐渐成为大宗师。首次通关后发现《轮回丹经》，可在下一世保留少量丹道理解。

叙事采用**短对话、任务文本、事件卡片**，避免大量过场动画。

## 3.2 五章节建议

| 章节 | 目标时长（参考） | 核心解锁 | 章节结束条件 |
|---|---:|---|---|
| 第一章：破炉丹童 | 30 分钟 | 基础丹方、商店、售丹 | 晋升一品丹师 |
| 第二章：初窥丹道 | 60 分钟 | 委托、低阶探索、新丹炉 | 晋升三品丹师 |
| 第三章：异火现世 | 90 分钟 | 异火收服、流派抉择、特殊材料 | 晋升六品丹师 |
| 第四章：丹会争锋 | 120 分钟 | 高品阶丹方、古方研究、丹会 | 晋升九品丹师 |
| 第五章：问鼎丹道 | 60 分钟 | 终极神丹、结局考核 | 晋升炼丹大宗师 |
| **合计** | **360 分钟** | | 约 6 小时基线 |

这些时间是**体验目标**，不是固定时钟或强制等待；应通过测试调整。

## 3.3 结局

- **丹道大宗师（标准）**：完成九品考核与最终神丹炼制。
- **九转丹圣（特殊）**：在当前周目达成指定的极品神丹条件。
- **百草药祖（特殊）**：达成特定研究、材料发现和变异丹药条件。

普通结局应完整，不将“真实结局”锁在反复通关之后。多周目为可选扩展体验。

# 4. 核心系统：丹方、药材、丹炉、异火、道具、丹药

## 4.1 通用内容规范

每个静态定义必须包含：`id`、`name`、`description`、`tier`、`tags`、`unlock`。使用不可变的英文下划线 ID（例如 `recipe_juling`）。保存使用 ID，不保存可本地化的显示名称。所有配置通过验证器校验引用、范围及唯一性。

## 4.2 丹方 Recipe

基础字段：

| 字段 | 类型 | 意义 |
|---|---|---|
| `id`, `name`, `description` | String | 唯一标识与显示 |
| `tier` | int | 丹方品阶 1～9 |
| `required_rank` | int | 要求的丹师品阶 |
| `base_success_rate` | float | 无加成成功率 [0,1] |
| `materials` | Dictionary | 材料 ID → 数量 |
| `quality_weights` | Dictionary | 成功后的四档权重 |
| `base_sell_price` | int | 凡品参考售价（灵石） |
| `tags` | Array[String] | 木、火、冰等属性 |
| `unlock` | Dictionary | 商店、晋升、委托、研究等 |
| `special_rules` | Array[String] | 可选效果 ID |

丹方获得方式：基础丹方由师父传授；常见丹方在商店买；中高阶由晋升、委托和秘境残卷解锁；隐藏丹方由研究或特殊结局线索获得。

### 丹方研究（轻量版）

- 每次炼丹得到少量`research_points`；首次成功、首次获得新品质可额外奖励。
- 消耗研究点数＋指定残卷解锁目标丹方。
- 关键主线丹方采用**可计算的研究进度**，不能完全依赖稀有随机掉落。
- 不开发任意材料自由组合生成无限丹方；仅使用预定义候选丹方。

## 4.3 药材 Material

类型：基础灵草、高级灵草、矿物、妖兽素材、天地灵物。字段包含价格、品阶、属性、可购买性、是否可重复获取、纯度（如启用）。

**简化决定：** 首版不做“逐件随机纯度”的库存堆叠复杂度。仅区分普通材料和少量 `refined_` 特殊版本；效果相当于固定高纯度药材。这样避免库存变成大量不可合并的物品实例。

来源：商店无限供应基础草药；委托赠送材料；探索获取高阶素材；少量通过失败丹渣研究兑换。**取消传统灵田系统**，以后可添加“自动药圃”为可选被动补给，但不进入首版主线。

## 4.4 丹炉 Furnace

属性：成功率修正、品质权重修正、失败返还率、额外成丹率、适配标签、特殊效果。固定 6 座主题丹炉：

| 丹炉 | 定位 | 效果方向 | 建议获取 |
|---|---|---|---|
| 凡铁丹炉 | 教学起步 | 无修正 | 初始 |
| 青木灵炉 | 稳丹 | 成功率提升 | 商店、首阶奖励 |
| 赤炎丹炉 | 上品 | 对火属性丹方增加品质收益 | 商店、委托 |
| 玄冰丹炉 | 回收 | 失败返还部分素材 | 特殊任务 |
| 紫霄雷炉 | 冲品 | 降低成功率、提高极品权重 | 秘境、丹会 |
| 九龙神炉 | 终局 | 满足条件时概率多丹 | 高阶考核 |

首版丹炉为永久装备，升级仅提供 0～2 个固定成长档位；不做无限随机重铸，防止测试组合爆炸。

## 4.5 异火 Flame

每次只装备 1 种，永久拥有，轮回时按规则重置。建议 5 种：

| 异火 | 核心特点 | 建议获得 |
|---|---|---|
| 凡火 | 无加成 | 初始 |
| 地心灵火 | 泛用稳定加成 | 火山探索 |
| 青莲异火 | 木属性、品质增益 | 青莲试炼 |
| 寒髓冰焰 | 回收、材料保护 | 冰域事件 |
| 紫霄雷火 | 极品、变异联动 | 高阶雷劫事件 |

异火“收服”采用事件卡＋收集指定资源＋一次试炼，不增加即时战斗系统。主线所需火焰至少有一条确定性获取途径。

## 4.6 加成消耗品 Consumable

- 稳丹符：成功率增加。
- 聚灵符：良品／上品权重增加。
- 护炉玉：失败返还更多基础材料。
- 双生符：成功后概率额外获得 1 枚。
- 九转丹引：提高指定品阶的极品权重。
- 研究香：本炉研究心得增加。

MVP 每炉最多带 **1 件**消耗品；正式版最多 **2 件**，但同一效果类别不允许无限叠加。效果顺序必须固定并可测试。

## 4.7 丹药 Pill

丹药实例保存 `recipe_id`、`quality`、`mutation_id`（可空）、`quantity`。若无独立随机词条，同类丹药应可堆叠；不要为每枚普通丹药创建独立复杂对象。

四档品质：凡品（Common）、良品（Good）、上品（Superior）、极品（Legendary）。

- 品质提高售价、委托价值及图鉴完成度。
- 变异是**额外标签**，并不取代品质。变异概率只在符合规则且炼丹成功后判定。
- 多丹效果发生在品质与变异确定后，默认同一炉额外产丹沿用此次品质；以后如需逐枚判定必须明确修改设计和测试。

建议的默认售价倍率：凡品 ×1.0、良品 ×1.5、上品 ×2.5、极品 ×6.0。变异可另加固定奖励或指定订单收益，不直接让普通商店售价无限膨胀。

# 5. 概率炼丹详细规则

## 5.1 核心公式

所有修正使用 **小数概率** 存储：`0.05` 表示 **增加 5 个百分点**，不是乘以 1.05。

```text
raw_success_rate = recipe.base_success_rate
                 + rank_bonus
                 + furnace_bonus
                 + flame_bonus
                 + material_bonus
                 + consumable_bonus
                 + strategy_bonus
                 + world_bonus

final_success_rate = clamp(raw_success_rate, 0.05, 0.95)
```

普通炼丹默认成功率限幅 5%～95%；特殊剧情或通过确定性研究兑换的炼制可走专用规则，不伪装成普通概率。

**例子：** 50% 基础＋10% 熟练度＋8% 丹炉＋5% 异火＋5% 材料＋10% 符箓－15% 高阶惩罚＝**73%**。

## 5.2 品质权重

成功判定通过后才抽取品质。权重可以不事先归一化，但必须非负且总和大于 0。推荐将权重调整设计成**从低品质向高品质转移权重**，而不是直接无限堆加总概率。

示例初始权重：

| 品质 | 成功后权重 | 条件概率 |
|---|---:|---:|
| 凡品 | 65 | 65% |
| 良品 | 25 | 25% |
| 上品 | 9 | 9% |
| 极品 | 1 | 1% |

“提高极品权重 4 点”的处理示例：从凡品权重转移 4 点给极品，得到 61/25/9/5；如凡品不足，应按明确规则依次从良品、上品转移或拒绝配置。**不允许隐式产生负权重。**

正确区分：

- 成功率 `P(S)`。
- 成功后极品条件概率 `P(L | S)`。
- 单炉极品概率 `P(S∩L)=P(S)×P(L | S)`。

例如：成功率 80%，成功后极品率 5%，单炉出现极品的概率为 **4%**。

## 5.3 策略参数（平衡起点）

| 方案 | 成功率修正 | 品质权重变化 | 用途 |
|---|---:|---|---|
| 正常炼制 | 0 | 无 | 基准 |
| 稳妥炼制 | +0.10 | 极品权重 -1，转给凡品；下限为 0 | 委托、赚钱 |
| 冲击极品 | -0.15 | 凡品权重 -5，极品 +5 | 图鉴、冲高价 |

这是示例值，**不是最终平衡结论**。先实现两种模式时可只保留稳妥与冲品；“正常炼制”作为内部基准或后续第三选项。

## 5.4 触发顺序（必须统一）

1. 验证丹方、品阶、装备所有权、素材数量、消耗品数量。
2. 使用同一个规则函数计算并冻结该炉的概率快照。
3. 原子性扣除材料和消耗品，记录一炉开始。
4. 从炼丹专用 RNG 抽取**一次成功结果**。
5. 若失败：按规则退还材料或产出丹渣、发放失败心得；跳至步骤 9。
6. 若成功：抽取**一次品质结果**。
7. 若满足条件：使用独立后续抽取判断**变异**。
8. 若满足条件：判断**额外成丹**，生成丹药。
9. 结算经验、委托进度、图鉴、统计、成就、行动数。
10. 返回只读结果快照；UI 播放动画，不应再次掷骰。
11. 自动存档或标记需保存状态。

## 5.5 概率预览原则

- 预览是纯计算，**不能消耗 RNG、物品或灵石**。
- 预览显示成功率、成功后的四档品质分布、单炉极品总概率、消耗材料、失败返还规则。
- 配置发生变化时实时刷新；点击开炉时服务端式地再次计算最终快照，避免 UI 预览过期。
- UI 动画使用另一条视觉 RNG 流，绝不改变炼丹结果。
- 不能因连续失败暗中提高或降低显示概率。若设计保底，必须明确告知并单独描述规则。

## 5.6 防重复提交

- 点击开始后按钮立刻禁用；服务层也使用 `action_id` 或处理锁防重复。
- 同一提交不可二次结算。
- 失败的校验不得消耗素材或 RNG。
- 一次批量炼制逐炉结算，每炉都有唯一结果和耗材明细；可一次显示汇总。

## 5.7 示例经济演算

假设一品聚灵丹：

- 基础成功率：80%。
- 材料：灵草 ×2（每株 4 灵石）、青花 ×1（每朵 6 灵石），总成本 **14 灵石**。
- 基础售价（凡品）：26 灵石。
- 成功后品质权重：65%、25%、9%、1%。
- 品质售价倍率：1.0、1.5、2.5、6.0。
- 炼丹失败可获得价值约 3 灵石的丹渣（出售或研究二选一，不能双重兑现）。

成功时平均售价：

```text
26×(0.65×1.0 + 0.25×1.5 + 0.09×2.5 + 0.01×6.0)
= 34.06 灵石
```

单炉预期净灵石收入（假定丹渣出售）：

```text
0.80×34.06 + 0.20×3 - 14 = 13.848 灵石
```

即在假设价格下每炉约 **+13.85 灵石**，仅说明如何计算，并非承诺实际玩家盈利水平。需要进一步考虑委托溢价、装备成本、消耗品与批量炼制。

# 6. 资源获取、商店、委托与秘境

## 6.1 为什么不做传统灵田

目标只有 4～8 小时，完整种植周期、收获、升级、季节与浇水会分散主要操作，并使炼丹节奏被等待打断。首版采用：

1. **基础药材商店**：稳定、可预计。
2. **宗门委托**：明确的赚钱与成长目标。
3. **秘境事件卡**：短时冒险、稀有资源与随机惊喜。
4. **丹渣研究／兑换**：失败也产生资源价值。
5. **免费采药**：无灵石时的安全网。

未来如需留一点经营感，可增加不需要手动操作的自动药圃，按完成的炼丹次数产出基础灵草，但不影响主线进度。

## 6.2 商店

- 基础草药与低级符箓常驻，无数量限制。
- 新品阶商品随晋升解锁。
- 稀有材料可设置固定的任务／秘境获取，不用商店无限供应。
- 批量购买需要可预览总价，交易失败不产生部分扣款。
- 卖出价格与买入价格分开配置，默认不能通过直接倒卖套利。

## 6.3 委托

字段建议：`id`、`required_recipe_id`、`min_quality`、`quantity`、`reward_spirit_stones`、`reward_exp`、`reward_items`、`unlock_conditions`、`repeatable`。

三种委托：

- **基础委托**：少量低阶丹药，稳定收入，可重复。
- **精英委托**：指定上品、特殊属性，奖励较好。
- **晋升委托**：章节关键任务，完成后允许考核。

委托面板始终至少存在一个玩家当前可完成的基础委托；高难委托不可无故挤占全部任务槽。

## 6.4 秘境事件

采用 2D **事件卡选择**，不制作战斗地图。

事件定义：入口条件、权重、文本、可选行动、行动消耗、概率奖励、后继状态、保底资源。

示例：

> 【青岚山谷】发现一株百年灵芝。  
> A：稳妥采摘：必得普通灵芝 ×2。  
> B：冒险深入：消耗护身符，有 30% 概率取得百年灵芝；失败获得常规药材。  
> C：离开：无收益。

高级丹方、异火与炉胚至少拥有一条**任务保底路径**；随机掉落只提供提前获得或额外数量。

## 6.5 免费资源保底

- 玩家可以免费采集最低阶材料，行动次数有限但**不会永久失效**。
- 即使灵石为 0，也可以通过免费采集 → 基础丹药 → 委托恢复经济。
- 关键剧情稀有材料不允许因为误售而永久锁死；要么不可出售，要么存在重新获取途径。

# 7. 灵石经济和防卡死设计

## 7.1 灵石收入

丹药出售、宗门委托、探索奖励、成就与考核奖励。

## 7.2 灵石支出

药材、辅助道具、丹方、丹炉、研究、异火试炼准备。高级装备是重要的中后期灵石消耗项。

## 7.3 设计约束

- 灵石余额 `>= 0`；背包数量为非负整数。
- 游戏逻辑中禁止静默透支。
- 买卖、委托交付和炼丹均通过事务服务变更状态。
- 基础丹药配合常驻委托应有正向经济路径。
- 极品流可以有高方差甚至负期望灵石收益，但要提供图鉴或终局目标价值。
- 不能依靠“只有 1% 掉率的物品”解锁主线。
- 倒卖材料不会无限盈利；丹药加工收益应以投入材料、失败风险和任务要求为代价。

## 7.4 平衡评估维度

每个品阶检查：

| 指标 | 目标 |
|---|---|
| 平均每炉净收益 | 有可持续的普通路线 |
| 升级装备所需炼丹次数 | 有明确、合理的阶段目标 |
| 连续失败时的恢复能力 | 能回到基础循环 |
| 稀有材料获取次数 | 不应成为长时间随机堵点 |
| 不同流派有效性 | 至少一种优势场景和劣势场景 |
| 批量炼丹收益 | 与逐炉相同规则，无额外隐藏加成 |

# 8. 丹师晋升、天赋和流派构筑

## 8.1 丹师品阶

`0=丹童，1=一品丹师，……，9=九品丹师，10=炼丹大宗师`。

每次晋升需满足：

1. 丹道经验达到门槛。
2. 达成一个可追踪的丹道成就（如成功炼制本品阶丹药）。
3. 完成一次明确的考核任务。

晋升解锁新丹方、商店库存、秘境、装备和任务。不能仅靠“经验条满”晋级；也不能因为始终未抽到极品而卡主线。

## 8.2 主线晋升示例

| 品阶里程碑 | 核心目标 | 代表能力 |
|---|---|---|
| 丹童→一品 | 炼成首枚聚灵丹，完成师父委托 | 商店／出售 |
| 一品→三品 | 完成指定订单并获得基础研究心得 | 低阶探索／新丹炉 |
| 三品→六品 | 收服首个异火、通过丹会 | 首个主要流派成型 |
| 六品→九品 | 研究古方、完成高品阶丹会 | 高阶构筑 |
| 九品→大宗师 | 炼成太初造化丹并完成认证 | 通关／轮回 |

中间各品阶可以用精简订单、炼丹成就和较短剧情连接，不应每阶都开发独立复杂副本。

## 8.3 三次重大天赋抉择

三品、六品、九品各一次“三选一”；每轮只能选其中一个，下一世重置。

示例三品抉择：

- **丹心稳固**：稳定成功并降低部分失败损失。
- **烈火淬丹**：牺牲成功率提高极品权重。
- **百草衍化**：新增指定材料替换／研究路径。

要求不同选项**改变玩法或决策**，避免清一色“+5% 成功率”。

## 8.4 首版三大流派

### 稳丹流

目标：稳定正收益、委托和常规晋升。核心道具：青木灵炉、稳丹符、地心灵火。弱点：极品图鉴收集效率较低。

### 极品流

目标：高品质订单与九转丹圣结局。核心道具：紫霄雷炉、雷火、九转丹引。弱点：成功率下降、灵石波动大。

### 回收流

目标：以低失败损失挑战高成本丹方。核心道具：玄冰丹炉、寒髓冰焰、护炉玉。弱点：单次极品收益与快速大量出丹能力有限。

变异流、多丹流可放在后续内容扩展，不应阻塞首版。

## 8.5 平衡原则

每个装备效果都应有目标用户、使用时机、成本和限制。高级装备不一定严格替代低级装备；至少存在 2～3 个可用构筑，使玩家愿意第二周目尝试其他路线。

# 9. 多周目：轮回传承与天地变数

## 9.1 轮回开启条件

首周目完成大宗师结局后解锁。玩家可选择留在当前周目继续图鉴收集，或在明确提示后开启下一世。开始轮回是**主动操作**，不可因剧情自动覆盖存档。

## 9.2 轮回流程

```text
达成结局 → 统计本世成就 → 解锁可选传承
→ 从符合条件的 3 个传承中选择 1 个解锁（无新项时给替代奖励）
→ 结算永久图鉴、记录与成就 → 保存元进度
→ 选择下一世携带的有限传承 → 生成世界规则
→ 确认开始 → 创建新周目 → 从丹童重开
```

## 9.3 继承与重置表

| 内容 | 下一世 |
|---|---|
| 灵石、材料、丹药 | 重置 |
| 当前拥有的普通丹炉和异火 | 重置 |
| 当前品阶、经验、任务、临时天赋 | 重置 |
| 当前丹方使用权限 | 按新周目解锁规则重置 |
| 历史图鉴发现、最高品质纪录 | 永久保留 |
| 已解锁传承、结局、成就 | 永久保留 |
| 教程跳过、快捷操作、批量炼丹许可 | 永久保留 |
| 历史周目成绩 | 永久保留 |

## 9.4 传承系统

- 初次轮回解锁传承栏，开局可装备 1 项；完成后续特定成就可装备 2 项。
- 已解锁传承永久收集，可在每次新周目开始前自由选择。
- 传承不无限堆叠；相同效果不重复叠加。
- 以独特规则为主，例如预先解锁一项材料替换、保留一种简化丹炉特性、增加一次探索选项。

示例 9 项传承候选：

| ID | 名称 | 作用方向 |
|---|---|---|
| `heritage_baicao` | 百草通灵 | 首次接触药材额外研究 |
| `heritage_luyin` | 本命炉印 | 指定炉类特性提前弱化生效 |
| `heritage_huozhong` | 异火火种 | 异火收服前获得一个特殊选择 |
| `heritage_wendan` | 稳丹心法 | 首次完成常规委托时额外收益 |
| `heritage_jizhuan` | 九转灵识 | 冲品可使用新的品质权重策略 |
| `heritage_huishou` | 残灰归元 | 丹渣回收效率提升 |
| `heritage_tuolu` | 古炉寻踪 | 秘境炉胚事件多一个选项 |
| `heritage_yandan` | 丹眼识真 | 解锁高级委托品质需求预览 |
| `heritage_yuanqi` | 元气初复 | 每世第一次资源短缺时获得基础补给 |

上表为**机制方向**，数值需另行验证。

## 9.5 天地变数

第二世起每轮选择／随机获得 2 条世界规则，至少其中一条偏向机会或新策略。例：

| ID | 名称 | 效果方向 |
|---|---|---|
| `world_lingqi` | 灵气复苏 | 高纯材料更易获得 |
| `world_kucao` | 灵草枯竭 | 商店普通药材更贵，秘境草药更多 |
| `world_huoling` | 火灵躁动 | 火属性丹药变异概率提高 |
| `world_dansheng` | 丹道盛世 | 订单奖励提高，品质要求提高 |
| `world_yiji` | 上古遗迹 | 丹方残卷和炉胚事件频率提高 |
| `world_jinhuo` | 天地禁火 | 高阶异火使用受限，凡火获得替代收益 |

每条规则配置：`tags`、`exclusive_with`、`weight`、`changes`、`min_run_number`。生成时校验冲突及可达性。

重要：不能出现例如“主线必须使用异火，但天地规则永久禁止所有异火”的死局。必要时提供替代路线。

## 9.6 本世丹道目标

开启新周目可以选择一个目标：

1. **问鼎丹道**：正常晋升，挑战最快成长。
2. **九转成圣**：重视极品丹药与对应结局。
3. **百草通玄**：重视研究、变异与图鉴。
4. **丹道极速**：在较少游戏行动数内通关（后续解锁）。

本世目标提供不同的任务、初期情报和少量奖励，避免仅改变文本标签。

## 9.7 防重复劳动

- 二周目可跳过新手教学。
- 已掌握的基础丹方允许批量炼丹和一键补货（具体解锁等级可在元进度保留）。
- 任务对话可快速跳过。
- 首周目的固定剧情事件在后续周目变为短文本或摘要。
- 保留历史最佳记录，使每世有可比较的成绩。

# 11. UI／UX、反馈与无障碍

## 11.1 主界面布局

推荐基准视口 1280×720，支持缩放及不同窗口比例。玩家主要用鼠标，也应支持基础键盘导航。

```text
┌──────────────────────────────────────────────────────────────┐
│ 丹师境界｜当前周目｜灵石｜主要任务                       │
├───────────────┬────────────────────────┬─────────────────────┤
│ 丹方列表      │       当前丹炉         │ 炼丹配置            │
│ 搜索/品阶筛选 │       异火效果         │ 成功率 / 品质权重   │
│ 配方详情      │       炼丹动画         │ 材料缺口 / 成本     │
│ 材料需要      │       出丹反馈         │ 策略 / 消耗品       │
├───────────────┴────────────────────────┴─────────────────────┤
│ 丹房｜商店｜委托｜秘境｜背包｜图鉴｜丹师｜轮回（已解锁） │
└──────────────────────────────────────────────────────────────┘
```

## 11.2 必需界面

1. 主菜单：新游戏／继续／图鉴／设置／退出。
2. 炼丹房：配方、装备、成功率、成本、开炉、结果。
3. 商店：材料、丹方、丹炉购买及丹药出售。
4. 背包：材料、消耗品、丹药和装备筛选。
5. 宗门委托：接受、追踪、交付、领取奖励。
6. 秘境事件：事件文本、多选项、掉落说明。
7. 晋升与天赋：条件追踪、选择天赋、考试。
8. 图鉴：丹药品质、变异发现、历史记录。
9. 轮回：本世结算、传承选择、天地变数、确认重开。

## 11.3 炼丹反馈

- 炼制前：明确概率与消耗。
- 炼制中：火焰、炉盖、音效与短动画；快速炼制可跳过。
- 成功：丹药品质、数量、价值与首次发现提示。
- 失败：明确损失、退还数量、丹渣和心得收益；不羞辱玩家。
- 记录：最近 10～20 炉日志可查看。

## 11.4 便利性和无障碍

- 可跳过重复动画，不影响概率。
- 可调节动效强度与闪光效果。
