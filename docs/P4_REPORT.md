## 已实现

- 主菜单启程并确认进入真实炼丹房，返回山门后继续同一会话；重开先说明会清除本次进度，取消不会重置。
- 左侧六丹方列表支持中文搜索和按实际内容品阶筛选，展示已习得/未习得、说明、材料持有/所需/不足；提供 1～10 炉购药与可购买丹方研习。
- 右侧选择已拥有丹炉/异火、最多一件符箓、三种策略；符箓库存和购符入口；最终成功率、成功后四品质、单炉极品率、消耗价值和失败返还全部调用服务。
- 点击开炉立刻结算并锁定操作，五秒通用动画、可跳过/快速揭晓；沉静模式停用动效并不等待。UI 不再次掷骰，也不做近失效果。
- 动画期间显示开炉前状态/报价，揭晓时才显示奖励和产物价值，避免提前泄露结果。
- 成功/失败弹层、材料消耗与返还、经验/心得、出售全部丹药与丹渣、收入确认、最近二十炉与悬停明细。
- 重复点击和计时器/跳过竞争不会重复结算；背景动作及键盘焦点在结果弹层中锁定，售出后焦点回到继续按钮。

GameSession 只通过既有服务修改业务状态，视图只读副本与回执，未在 UI 重复实现概率、交易价格或奖励公式。无新手强制成功、免费装备、虚构晋升或隐式发奖。

## 问题与处理

- 测试直接设置 LineEdit.text 不会模拟用户输入信号，修正夹具显式发出 text_changed，验证实际搜索流程。
- 初版右侧配置占据过多高度，图形检查后改为两列紧凑选择器，保留关键概率/成本/失败信息，同时提供详情滚动；放大丹炉展示空间。
- 首次图形检查发现已结算的顶部奖励和出售价格会提前暗示结果，改为动画期间的展示快照并新增回归，未修改实际概率或结算时机。
- 售出后禁用的出售按钮可能仍持焦点，改为收入确认并聚焦继续按钮。
- 会话初始化结果原本可能与内部状态共享引用，增加深复制并用回归验证；字典副本和历史同样隔离。
- 单独 check-only 运行依赖 Autoload 的视图时无法解析 AppSettings，改用真实项目启动和场景集成检查；没有把该独立检查报为通过。

## 设计细化、边界与下一步

P4 只增加会话协调、界面和展示反馈，不改静态数值、抽样或经济规则。动画固定五秒并可跳过；记录上限二十；购药一次 1～10 炉；本次会话用单调计时值生成种子。

当前进度只在运行内保留，已在引导、继续按钮提示和页脚说明；正式存档仍未实现。主线晋升、委托、秘境、免费采药、零资源恢复、完整商店/背包页、正式图鉴和轮回均未进入本阶段。高阶丹方及装备沿用原有锁定，不为 UI 测试向玩家虚假解锁，也不宣称完整一周目或 20～40 分钟内容已经完成。

P4 验收达到：无需调试控制台即可买材料→配置→开炉→看结果→出售，预览来自同引擎，重复输入不重复奖励，动画可跳过，窗口和焦点经过实际验证。
