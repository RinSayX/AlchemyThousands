## 已实现与设计细化

- 坊市提供材料、符箓、丹方、丹炉、异火五类；普通商品数量 1～99，永久物品每次一件，按既有 ShopService 检查来源、境界、拥有状态、库存和余额。丹药继续从丹房/结果弹层出售，允许收丹交单。
- 委托配置复用生成 `quest_run_N`。同模板最多一单进行中；交付优先消耗最低达标品质，高品质可代低品质；扣丹、灵石/历练/物品/异火奖励、完成标记、行动与统计一次提交。旧实例即使使用新操作 ID 也不能再领奖；重复模板需重新接单，一次性模板不能再生成。
- “宗门日常供丹”永久可重复，不受高难任务挤占，接单不计行动，交付计 1 行动。五个模板对应基础、精英与异火目标，未提前接入晋升条件。
- 秘境提供权重随机寻访或指定已开放地点。进入计 1 行动，选择与离开不额外计行动；卡片展示费用、成功率、成功/失败物品。待处理事件期间其他资源页和会话命令锁定，Esc/返回免费离开。事件实例 ID 阻止已结束卡片重复结算。
- 探索只使用 exploration 随机流，预览不抽；直接地点不抽地点 RNG，0%/100% 选项不抽结果 RNG。临时 RNG 随成功事务一起提交，支付不足、奖励溢出、无效实例等都不改变实际 RNG 或其他状态。
- 百年灵芝与养魂露有指定地点稳定选项；地心灵火可经一品确定性仪式或一次性委托取得。永久异火不重复入拥有列表。
- 免费采药补齐当前缺少的一炉聚灵丹药材（最多灵草×2、青花×1）。每趟三次，用尽后免费休整恢复三次；无需灵石或实时等待，永久可用。采药/休整各计 1 行动，均不消耗 RNG。

详细奖励和事件成本已记录 BALANCE.md。这些为候选数值，不是整体平衡结论。允许提前采得高阶素材，炼制仍由丹方/境界限制；稳定素材路径避免主线未来依赖稀有随机成功。

## 问题与处理

- 扩展忙碌状态后，旧 `finish_brew` 不能再用“是否忙碌”推断有丹药回执，改为显式检查待揭晓结果；秘境状态不会错误进入丹药揭晓。
- 内容通用 unlock 允许 initial，但新资源服务需要 required_rank；为委托/事件强制 rank 解锁并增加非法配置回归，避免合法加载后访问缺失字段。
- 随机结果先抽后发奖可能遇到库存溢出，使用临时 RNG 快照与候选事务；双分支溢出夹具确认费用、RNG 与事件都保持原样。
- 图形检查发现跨页会保留上一事件提示，改为每次打开/切页显示当前页说明，并在最终 UI 回归中验证。
- 新测试复用既有错误契约 `ACTION_DUPLICATE`，并对 Variant 返回值显式声明类型；早期开发检查失败均已修复，最终读取完整完成摘要确认 508 项通过。
