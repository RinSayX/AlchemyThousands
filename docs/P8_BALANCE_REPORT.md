# P8 首批经济与流派平衡报告 · 2026-11-19

本批结论是：现有规则具备可恢复的通关路径，但高阶冲品、低阶回收投入、免费资源的现金旁路和后世传承收益仍需分开处理。正式配置保持P7原值，以下提案尚未应用；这不是P8目标内容或真人时长验收完成声明。

## 样本与假设

基准 Godot `4.5.stable.official.876b29033`。主实验21场景×4政策×8种子，672条真实事务通关政策样本；另有同矩阵672条零资源压力样本。840个品阶条件探针各10000炉，61个装备敏感性探针各100000炉，共1450万次规则抽样。原始通关炉次另计，不把抽样当作1450万次完整背包事务。

场景包括首世标准世界、九项单传承、全部10个合法机会世界对及一组双传承。后世拥有传承和世界均为隔离控制变量，未模拟永久解锁历史；并不表示第二世能任意取得九项传承，或第三世已经解锁该双携带组合。世界对等量测量，未按实际生成概率加权。

三种政策至多自然尝试8炉考核丹，缺合格丹则攒心得研制；研究对照直接研制。稳丹支援时重复基础委托，其余仅完成主线供丹。所有支援均可用免费基础采药/休整；这是一套明确的可行政策，不是最优控制、随机玩家分布或单纯只换策略按钮的公平实验。一品装备/异火通过真实支出取得，高阶资源按确定性地点获取。

成本按正式逐单位价格与返还取整。单炉净值把退回材料计为库存获取价值；通关现金账只记真实交易，不把返还材料再次当作现金。条件探针假设已拥有装备，不含初始购置；全流程包含。详细口径及复现命令见 [模拟器说明](P8_SIMULATOR.md)。

上述P10/P50/P90采用最近秩；每组只有8个种子，P10/P90在本批等于样本最小/最大值。它们描述这批固定政策，不能作为玩家总体的尾部风险估计。支援炉数包含攒钱、心得和历练，不能全部当作“被失败逼迫的恢复”。玩法行动还不包括所有购买、出售和接单；事务数也不能直接当UI点击数。

## 资金耗尽、恢复与旁路

正常样本中有560/672条出现过至少一次需额外筹资的短缺，均按原政策继续完成。另将现金和背包清零的672条压力夹具，672/672条恢复到可购买一炉基础药材的现金：本批最多7次支援开炉，0恢复失败、0步数超限。标准世界门槛14灵石，草药涨价世界为18灵石；所有压力现金账均一致。此结论仅限这些起始夹具和种子，不能推成任意中途状态的全称证明。

另用一品零资源夹具执行100次“免费矿脉→出售材料”的正式服务事务，获得700灵石，100玩法行动/300事务，0炉。这是现有确定性奖励7灵石售价的直接结果，不是概率Bug；基础山谷的免费药材也可出售，单次4灵石，枯草世界则有增量。普通采药/休整本身也提供无限恢复。

因此“永远可以恢复”与“货币稀缺”不能混为一谈。无实时等待的无限出行会把资金瓶颈变成重复操作，若只压低炼丹售价、提高药材价格，玩家仍可绕开炼丹刷原料现金。当前样本未自动选择矿脉刷钱，现金表不能称为所有赚钱路线的上界。
